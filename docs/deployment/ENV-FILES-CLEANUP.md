## Environment Variable Priority (Next.js)

Next.js loads environment variables in this order (highest priority first):

1. **Process env** (already set in terminal)
2. `.env.$(NODE_ENV).local` (e.g., `.env.production.local`)
3. `.env.local` ← **Your active file**
4. `.env.$(NODE_ENV)` (e.g., `.env.production`)
5. `.env`

**For local development**: `.env.local` takes precedence  
**For Vercel deployment**: Vercel environment variables take precedence
